# 校正ナビ

測定器・工具の校正を、QRコードで読んで、その場で入力できるWebアプリです。台帳・期限の確認から、ISO 9001 の監査での提示を想定した「定期校正結果報告書」（A4）の自動作成までを、1つで行います。

- 測定器のQRを読み取る（カメラ／写真）と、管理番号・名称・保管場所・前回の校正日・次回の期限・基準値と公差が1画面で開き、実測値・判定・担当者をその場で入力して保存できます。
- 台帳で、未実施・合格・要調整・異常・実施期間外を一覧できます。QRラベルのA4印刷、測定器の追加・編集ができます。
- 各測定器に前回の校正日と校正周期（月）を入れておくと、次の期限の月の1日から期限までが校正期間になり、自動で「今回の実施」に切り替わって、進み具合を数え直します（前回までの結果は履歴に残ります）。最初の画面に、今年の校正期間と、いま校正期間中かどうかが出ます。
- 生産管理システムとの連携用に、台帳のCSV取り込みと、校正の実施結果のCSV書き出しができます。
- 校正の記録には、記録した日時・担当者・使った標準器と基準値・公差・判定・処置内容が残ります（監査証跡）。基準値をあとで直しても、過去の記録は当時のままです。
- 報告書は、実施結果のまとめ・総括・処置内容・一覧表・監査証跡ログつきで、A4に印刷／PDF保存できます。

## 技術と保存先
- データベース・サーバー不要の静的Webアプリ（React + Vite + TypeScript）
- データは、この端末のブラウザ（localStorage）の中だけに保存します。外部への通信・送信はしません。QRの読み取りも端末の中で行います。
- 初めから入っている測定器10台・校正記録は、架空の見本です。

## 開発
```
npm install
npm run dev          # 開発用
npm run build:pages  # docs/ に公開用を作る（GitHub Pages: main の /docs）
```
